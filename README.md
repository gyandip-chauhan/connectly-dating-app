# Connectly 💠

> **Meaningful Connections Through Sonic Identity & Premium Aesthetics.**

Connectly is a high-fidelity dating and social discovery platform that leverages **Sonic Identity Analysis** to foster deeper human resonance. Built with a signature **"Crystalline"** aesthetic, the platform blends high-end glassmorphism with immersive motion design to create a premium, atmospheric user experience.

---

## 🏗️ Core Pillars

### 🔊 Sonic Identity
Advanced audio analysis that decodes emotional frequency, fluency, and tone to build a unique "Sonic Footprint" for every user.

### 💠 Crystalline Design
An immersive interface featuring high-fidelity glass containers, pulsing radial depth, and editorial typography designed for a premium, tactile feel.

### 🧘 Zen Journal
A minimalist writing sanctuary for "Inner Dialogue," allowing users to imprint their thoughts with real-time sentiment frequency tracking.

### ⚡ Resonance Discovery
A perspective-based discovery flow where interaction is driven by "Resonance" rather than simple swipes, backed by complex compatibility logic scores.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 14, Tailwind CSS, Lucide React, Framer Motion
- **Backend**: Supabase (Auth, PostgreSQL, Real-time)
- **State**: React Hooks & Context API
- **Aesthetics**: Custom Glassmorphism UI System ("Crystalline")

---

## 🚀 Getting Started

1. **Environment**: Configure your `.env.local` with Supabase credentials.
2. **Install**: `npm install`
3. **Run**: `npm run dev`

---

## 🎨 Design Philosophy: "Crystalline"

Connectly moves away from flat, generic UI towards an immersive, layered experience. 
- **Depth**: Using `backdrop-blur-xl` and pulsing radial gradients to create space.
- **Micro-Animations**: Staggered entrances and hovering effects that make the UI feel alive.
- **Editorial Polish**: High-contrast, tracked typography (`font-black uppercase`) for a premium brand identity.
